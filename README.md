# dsh-skills-site

Standalone promotional site for the DSH Skills Codex plugin and the
DeepSeek Harness comparison story. Static, dependency-free `index.html`:

- install commands (copy buttons)
- the three skills
- an interactive box that generates a paste-ready analysis prompt for any repo
- measured comparison highlights with links to the full data

Published via GitHub Pages: https://coffee-man666.github.io/dsh-skills-site/
